# User tasks

Open work that's blocked on something only you can do: a physical device, an external account or subscription that needs your own login, an OAuth consent screen, or a subjective judgment that only forms by actually living with the product for a while. Everything else - even work with a decision embedded in it - stays in `now.md`, `soon.md`, `later.md`, or `security.md` because it can be implemented (and the decision resolved in conversation) without you doing anything outside this session. Once the blocking step here is done, report back; any follow-up implementation work moves into one of those files.

Ratings are 1-10, importance/urgency, my call - reorder or override as you see fit.

# User tasks

Open work that only the owner can unblock: a physical device, an external account or subscription that needs their login, an OAuth consent screen, or a judgment that forms only by living with the product. Everything else, even work with a decision in it, stays in `now.md`, `soon.md`, `later.md` or `security.md`. Once the blocking step is done, report back; follow-up implementation moves into one of those files.

Ratings are 1-10 for importance and urgency, a suggestion the owner can reorder.
